EVE Assistant — Desktop privacy notice

This proposed notice covers the desktop release supplied by Bridgetek Pte Ltd, including its three local MCP integrations.

Processing in the host platform

Prompts, uploaded files and generated responses are processed by the ChatGPT or Codex environment you choose. Local MCP tools can return query text, local paths, source snippets, selected file content, indexed references, command arguments and diagnostics into that conversation. The host platform's applicable privacy terms, retention controls and workspace settings govern that processing. Running a tool locally does not mean its returned content stays outside the AI conversation.

Local tools and access

The EveApps servers read configured local repository checkouts. They provide reference retrieval, sample lookup, scaffold text, code checks and build-command suggestions. Configure only project material you are authorized to disclose. EAB can inspect local assets and, after the applicable approval, run installed EAB programs to create or overwrite outputs or interact with connected hardware. Repository/EAB paths are stored in a per-user local configuration file. Users can change or remove that configuration and disable or uninstall the integration through the host.

Separate services and optional functions

This integration adds no independent telemetry or Bridgetek-hosted conversation backend. The bundled EAB server includes optional GitHub installation/update checks and host-model sampling; these can involve their respective services when invoked. Separately installed development tools, hardware software and host integrations retain their own data practices. Do not provide credentials or private material without authorization.

Bridgetek support

Installing this plugin does not grant its creator access to individual private conversations. Information you separately send to Bridgetek support is handled under the Bridgetek Privacy Policy and existing support procedures.

Review host-platform settings for conversation retention and deletion. Future backend, analytics or other collection changes require this notice to be updated before release.
