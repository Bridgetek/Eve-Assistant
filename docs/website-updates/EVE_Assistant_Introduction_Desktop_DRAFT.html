EVE Assistant — Desktop introduction

Bridgetek EVE Assistant combines engineering guidance and technical references with local tools for EVE application and asset development. This desktop version includes EAB, EveApps-BT82X and EveApps-Pre82X MCP servers.

How customers use it

Use a supported desktop ChatGPT or Codex environment with a local thread. Install Node.js, obtain the appropriate official EveApps repository checkout, configure its absolute local path and enable the plugin's MCP connections. Obtain the separate Rust EVE Asset Builder CLI distribution from https://github.com/Bridgetek/EAB-CLI for actual asset operations; keep eab_tools.exe, exts/ and dependencies/ together and select rust during setup. The documented binary distribution requires Windows 10/11 x64. Node.js is still needed for the MCP adapter. The separate EVE Emulator repository at https://github.com/Bridgetek/Eve-Emulator provides Windows binaries and Ubuntu 24.04 amd64 packages; the current example projects target Windows. Emulator installation and application execution are separate prerequisites, not additional MCP tools supplied by this plugin. Availability and installation depend on the host platform and plugin publication status.

Describe your chip, display, host platform and task. The assistant can retrieve indexed API references, inspect authorized local repository sources, find samples, propose screen scaffolds and build commands, and guide asset conversion. EAB execution requires approval for the exact operation. Source checks and build-command suggestions do not establish compiler, emulator or hardware success.

This plugin is for local development workflows and does not provide a hosted remote MCP service. It offers no payments or purchases. Host-platform or independently selected service fees remain governed by those services.
